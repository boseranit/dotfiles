# bose-hub

Debian 13 (Trixie), x86-64. This profile uses the shared login tools and
configuration without `vostro`'s research paths or filesystem mounts.

```sh
./bootstrap.sh --machine bose-hub
```

[Homelab's bose-hub runbook](https://github.com/boseranit/homelab/blob/main/hosts/bose-hub/README.md)
owns WireGuard, service configuration, application storage, and backups.
